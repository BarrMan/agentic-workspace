# OpenTUI Workspace Behavior Matrix

**Status:** The current native behavior table supersedes conflicting Phase 0 targets below. Legacy source anchors describe the pre-cutover implementation.

## Current native behavior

| Area | Current contract |
|---|---|
| Terminal ownership | One retained `EmbeddedTerminalRenderable` per session owns parsing, rendering, input encoding, cursor, and scrolling. Tmux only hosts processes. |
| Fullscreen | `f` displays same live terminal without workspace chrome, reserving one bottom row for visible Ctrl+Q exit hint. |
| Agent exit | `Ctrl+C` or `Ctrl+Q` leaves focused input/fullscreen without interrupting agent. Navigation `Ctrl+C` exits; `q` never exits. |
| Layout | The task list uses 30% width and toggles with `Shift+[`. `Space` shows or hides details in normal flow above the preview. Details use roughly 30% of the right-region height; collapse expands the same retained terminal. The details border carries a right-aligned collapse hint. Modal and preview backgrounds are neutral. |
| Statuses | Inside Tasks, native Box/Text tabs follow TTT v1.6.0 `tabbar_widget.go` geometry: the active tab is a three-row cap whose reversed bottom seams open into the task viewport, and inactive labels rest on a shared baseline at natural width plus surrounding spaces. To Do is blue, In Progress is yellow, and Done is bright green; custom statuses remain neutral. Selection adds bold text and raised chrome without a text-background highlight. Labels keep the `#1f1f1f` background and borders are `#555555`. The Tasks title carries the count; there is no per-tab count, underline, or fixed cell. Keyboard and mouse click navigation both work, `Left`/`Right` wrap through configured tabs, and clickable `◀`/`▶` scroll overflow. This composition requires no additional package or custom renderer. |
| Activity dots and selection | Green dot marks every visible task with current active `starting` or `running` session, selected or unselected. Stopped and error history does not add a dot. Selected tasks use dark text on light slate, with a darker green dot for contrast. Selection remains visible outside task-list focus. |
| Task viewport | Up/Down preserves the visible window until selection crosses its top or bottom edge, then scrolls minimally. Selection refreshes reuse the mounted surface, so the status tab row and task window keep their nodes and the first visible row. Status, filter, and view changes reset the window. |
| Boundary navigation | `g`/`G` selects the first/last filtered task. Workspace and board jumps stay in the active status tab or pane. Home/End remain supported. Empty panes do not select a task; editable input and agent focus do not trigger task jumps. |
| Navigation history | `Ctrl+[`/`Ctrl+]` restore task, filters, view, and status from at most 100 session-local states. |
| Shortcut editor | `?` opens help and `/` searches. Binding and description are separate columns in one shared responsive layout, so descriptions stay aligned across capture phases. `Enter` starts a native inline `Press key...` input. After the first stroke the binding shows as plain text and the pending native input moves right within the same column; the footer offers an optional second stroke, and a second stroke opens the unchanged Save/Discard footer. `Escape` after the first stroke confirms a single-stroke binding and clears the pending prompt. Left/Right chooses; Enter applies. Escape twice records single Escape. Only Save persists; conflicts, discard, and failed saves preserve the working binding. |
| Session picker | `s` lists task sessions newest first, marks active, and selects or resumes exact native conversation. |
| Session ownership | Normal workspace exit, SIGINT, and SIGTERM await owned-agent teardown while retaining durable records. Owned process groups receive TERM, then KILL if needed; children ignoring HUP do not outlive a proven stop. Failed or unproven stops retain ownership handles and capture files and do not mark records stopped. Pre-existing private tmux servers are refused, not adopted or killed. Selecting a task whose CLI-owned session still runs auto-attaches its real pane without lifecycle or ownership changes; externally owned sessions only detach. Stopped tasks never auto-resume. The selected-task passive probe never kills and settles only conclusive death or canonical absence; inconclusive results leave status unchanged. SIGKILL and hard crashes cannot run cleanup handlers. |
| Bootstrap | New agents receive only active-task sentence and instruction to wait. Starting does not begin task work or change status. |
| Skill isolation | `agenticworkspace skill` prints requested body. Launches load temporary session-scoped skills, not global/project skill installations. |
| Execution context | New task-manager launches use project root and strip task/project metadata environment variables. |
| Contextual footer | Saved sessions show Sessions/Handoff; no sessions show Enter/Start. Agent focus shows only leave-agent shortcut. Help retains less-used actions. |
| Agent settings | `,` opens fullscreen project-only Settings with a three-row header/footer and adjacent rounded category/content panes. Categories contains `Agents`; cyan marks pane focus. Fields show label, selected description, then a read-only value. Right enters fields; Left returns to categories. Tab/Shift+Tab, Up/Down, and mouse clicks select without editing. Enter begins editing; only then do arrows change preset options or native inputs accept text. Enter commits the field; Escape cancels its edit. Multiline paste and terminal-supported Shift+Enter provide environment newlines. At the selector, Space sets the default and `n` copies the adapter. Ctrl+S saves committed draft values only; Escape outside editing discards the whole draft. Horizontal scrolling stays hidden; the vertical scrollbar appears only on overflow. |
| Task configuration | Creation inherits project settings unless preset is chosen. `p` selects task override or restores inheritance. `h` selects replacement preset, retains predecessor until launch succeeds, and records link. Preset visibility does not claim live verification for additional providers. |
| Refresh performance | Workspace refresh reads session state once per project, not once per visible task. Pending navigation refreshes coalesce to the latest state while explicit refresh still awaits current-state work. Session state stays fresh; board cross-branch loading remains unchanged. |

See [session contract](./opentui-workspace-session-contract.md) for provider prerequisites and lifecycle boundaries.

## Historical Phase 0 characterization

## Reading this matrix

- **Observed legacy behavior** describes former tmux workspace, hidden `workspace-ui` children, and Board window.
- **Proposed target behavior** records original migration decisions. Later approved split-pane behavior supersedes conflicting preview and workspace-owned agent lifetime rules.
- **Decision** is explicit for every listed behavior:
  - **Retain** — preserve public/domain outcome and use existing service ownership.
  - **Change** — preserve outcome but change interaction, presentation, timing, or shortcut semantics.
  - **Remove** — delete legacy presentation behavior after public cutover and parity proof.

## Shortcut decision table

This table overrides legacy shortcut behavior only at approved migration phases. It records proposed behavior, not Phase 0 code changes.

| Context | Input | Observed legacy behavior | Decision | Proposed target behavior |
|---|---|---|---|---|
| Normal workspace | `Ctrl+C` | Quits workspace through legacy teardown and exits process. | **Change** | Only application-exit shortcut. If unsaved input exists, open existing confirmation before exit. |
| Normal workspace | `q` | Quits/detaches from navigation and Board paths. | **Change** | Never exits workspace. |
| Normal workspace | `Esc` | Does not quit from task navigation. It closes/backtracks in details, history, field editing, or footer search. | **Retain** | Only closes overlay or backtracks nested detail/history state. Never exits application. |
| Quick preview | `Ctrl+Q` | Legacy tmux return binding unzooms or selects task pane. | **Change** | Exit quick preview, withhold key from agent, restore prior workspace focus and normal routing. |
| Quick preview | `Ctrl+C` | No equivalent application-level quick-preview router exists; focused agent receives native pane input. | **Change** | Ignore and withhold key from agent. Do not exit application. |
| Quick preview | Any other key | Focused tmux agent receives native input. | **Change** | Send only to selected live agent. Run no workspace shortcut. |
