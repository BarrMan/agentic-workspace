# Consolidation decision sheet

> **Non-authoritative working sheet.** Not a contract. Answers here are applied to the owning contracts and to each document's disposition markers.

**1545 unconfirmed statements** remain. They are grouped **by document**, which is the boundary for a decision: answer for the whole group, select individual statements, or write a narrowing instruction.

## How to answer

Per group, write one of:

- `Discard all` — retire every statement as unapproved or historical.
- `Approve all` — fold every statement into the contract section named under it.
- `Select individually` — then mark statements `d` (discard), `i` (integrate), `?` (open).
- `Narrow: <instruction>` — reframe or split the group before deciding.

Class tags: `P` = proposal / unanswered claim, retirable by a policy answer. `G` = evidence, verification or safety gate — needs evidence or execution, not a decision.

If you would rather not go document by document, answer the two global policies in the next section and I will apply them across every group, then bring you only the `G` statements.

## Global policy answers (optional shortcut)

- `GP1` — retire every `P` statement that is an unanswered recommendation or an unapproved claim. (Recommended.) Alternative: retire only interview leftovers, keep planning proposals.
- `GP2` — retire every `P` statement that is a proposed API, candidate binding, aspirational target or speculative optimisation. (Recommended.) Alternative: keep proposals that belong to one specific document.
