## Audited implementation notes

- The project mode catalogue and agent presets are persisted within the project YAML configuration; root settings use the root YAML configuration and task overrides remain task metadata.
- Effective agent configuration is consumed via `resolveAgentConfiguration`; retained-session preset resolution goes through `resolveSessionPreset`, used by session-store/session services and the `mode-model.ts` capture operation. Application start/resume/ask consumption remains delegated to P5 and is not claimed verified here.
- No mode deletion implementation was changed. No history transfer or data repair was performed.
