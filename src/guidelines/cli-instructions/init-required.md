## AgenticWorkspace Initialization Required

This directory does not have AgenticWorkspace initialized.

To initialize the current project, run:

```bash
agenticworkspace init
```

For non-interactive defaults, run:

```bash
agenticworkspace init --defaults
```

For local projects without Git, run:

```bash
agenticworkspace init --no-git
```

After initialization, run:

```bash
agenticworkspace instructions overview
```

That command prints the current workflow guidance.
